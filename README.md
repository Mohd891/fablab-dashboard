# Fablab Al-Ahsa Management System — Training Project

## الفكرة
نظام متكامل يبدأ بموقع عام يمكن لأي زائر تصفحه بدون تسجيل دخول، ثم بوابات مختلفة حسب نوع الحساب:

- زائر: يتصفح الموقع والبرامج والمعلومات والتواصل.
- طالب: ينشئ حسابه بنفسه ثم يدخل إلى بوابته الخاصة.
- موظف: لا ينشئ حسابه بنفسه؛ حسابه ينشئه المدير.
- مدير النظام: يملك إدارة البرامج والطلاب والحضور والموظفين والتقارير والرسائل.

## الخصوصية
عدادات السعة، أعداد المسجلين، البيانات التشغيلية والتقارير التفصيلية تظهر داخل بوابة الإدارة فقط.
صفحات الزوار والطلاب لا تعرض أعداد المسجلين أو المقاعد المتبقية.

## بيانات المدير الافتراضية
- البريد: admin@fablab.local
- كلمة المرور: Admin@12345

يفضل تغيير كلمة المرور بعد أول دخول.

## التشغيل على XAMPP
1. ضع هذا المجلد باسم `fablab-dashboard` داخل `C:\xampp\htdocs\`.
2. شغّل Apache و MySQL.
3. افتح `http://localhost/fablab-dashboard/install.php` مرة واحدة.
4. بعد نجاح التهيئة افتح `http://localhost/fablab-dashboard/`.
5. بعد التأكد من التشغيل احذف `install.php` من مجلد المشروع.

## ملاحظات
- `api/db.php` وملفات PHP تحافظ على الجداول الموجودة وتحاول إضافة الأعمدة المطلوبة بدل حذف البيانات.
- التسجيل العام متاح للطلاب فقط.
- إنشاء حساب موظف يتم من المدير.
- تغيير البريد وكلمة المرور متاح من الإعدادات لكل مستخدم وفق صلاحياته.
